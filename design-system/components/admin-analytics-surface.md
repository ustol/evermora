# Admin analytics surface

Composed from existing UI primitives: `Card`, `Button`, `Badge`, `Table`, `Separator`, and tokenized chart/status colors.

## Purpose

Admin analytics surfaces summarize memorial activity, contribution review, payments/gifts, service edits, and family invitations with a calm trust-first tone.

## Structure

1. Page or section title in Chillax.
2. KPI row with quiet card surfaces.
3. Review queue or table with strong labels and visible status.
4. Optional utility rail for actions, filters, exports, or guidance.

## Status color

- Confirmed/completed: `--success`
- Needs attention/pending risk: `--warning`
- Failed/destructive/rejected: `--critical`
- Brand orientation/focus only: `--accent`

## Accessibility

Keep contrast high in both light and dark modes, provide text labels alongside color status, and preserve keyboard focus rings on row actions and filters.
